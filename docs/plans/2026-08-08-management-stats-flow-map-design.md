# Карта потока статистики: дизайн

**Цель:** заменить перегруженный линейный список событий компактной картой потока, которая показывает реальные значения на каждом шаге для любого периода и не превращает пустые или разреженные данные в ложные полосы.

## Почему текущий визуал недостаточен

- Общая заливка рельса визуально выглядит как значение даже тогда, когда `entered` равен нулю.
- Одна и та же высота и плотность применяются к одному дню и месячному периоду, поэтому малый период занимает слишком много места.
- Линейные полосы не показывают разницу между «вошли», «перешли дальше» и «потеряны».
- Ненормальная для когорты последовательность событий не должна выглядеть как классическая нисходящая воронка.

## Рассмотренные варианты

### 1. Несколько круговых диаграмм

Отклонено. Круг удобен только для части от целого. Несколько кругов скрывают абсолютные значения и плохо объясняют порядок событий.

### 2. Sankey/flow canvas

Отклонено для текущего этапа. Он эффектный, но для небольших выборок и не монотонных событий создает ложное ощущение причинного потока, а на телефоне плохо сканируется.

### 3. Гибридная карта потока, выбрана

Для каждого шага показываются:

1. номер и короткое название;
2. абсолютное значение `entered`;
3. доля от первого шага, только если когорта монотонна;
4. переход к следующему шагу (`advanced`);
5. потеря на этом шаге (`drop_off`) и остаток «в процессе».

Между шагами идет тонкая дорожка. Дорожка заполняется только по фактической доле, поэтому нулевой этап остается тонкой базовой линией. Самое большое падение получает единственный янтарный маркер. Для не монотонных данных подпись меняется на «окремі події», а проценты конверсии скрываются, чтобы не ввести в заблуждение.

## Поведение по плотности периода

- **Один день:** 10 компактных узлов в две строки; текст сокращается, подробности доступны по клику.
- **2–7 дней:** одна горизонтальная лента с равными узлами.
- **8+ дней:** та же карта с меньшими отступами, без изменения семантики.

Визуальная система не меняет смысл полей при смене даты. Меняется только плотность, чтобы один день не занимал высоту полноценной диаграммы.

## Интерактивность

- Клик/Enter на узле раскрывает одну строку фактов под картой: `вошли`, `перейшли`, `втрачено`, `у процесі`.
- Остальные узлы мягко приглушаются, активный получает тонкую цветную рамку.
- Escape, клик снаружи и повторный клик закрывают детализацию.
- `aria-pressed`, `aria-controls` и понятный `aria-label` дают тот же смысл клавиатуре и экранному диктору.
- Анимация только показывает изменение ширины и появление деталей; при `prefers-reduced-motion` она выключается.

## Цвет и иерархия

- синий: вход в этап;
- бирюзовый: переход дальше;
- янтарный: потеря;
- зеленый: подтвержденная оплата/доставка;
- нейтральный: этап без данных.

Цвет не используется без числа: декоративных заливок и «пустых» больших блоков нет.

## Проверяемые инварианты

- Сумма значений карты совпадает с API `funnel[*].entered`.
- Нулевые значения не создают заполненную полосу.
- При не монотонной последовательности проценты не отображаются как конверсия.
- Один и тот же HTML-контракт работает для пустого, однодневного и длинного периода.
- Нет горизонтального переполнения на 320px.
