## DJ6-BG-007 — commit-safe durable registration notifications

- [x] Registration notifications сохраняются как durable work после успешного
  commit и не зависят от best-effort отправки внутри registration request.
- [x] В delivery передаются persisted identifiers, а не ORM instance, пароль
  или иные чувствительные request-owned данные.
- [x] `next_attempt_at`, storefront transport, несколько получателей и
  per-target idempotency покрывают retry и частично успешную доставку.
- [x] Focused BG-007 gate после исправления: `27/27` тестов прошли.
- [x] System check, `makemigrations` check и `git diff --check` прошли.

Acceptance evidence: targeted regression scope, включающий исправленный
failure path, полностью зелёный. Более ранний объединённый gate дал
`396 passed, 1 skipped, 3 failed`; эти три failures были зафиксированы до
focused BG-007 fix. Полный suite из 400 тестов после focused fix намеренно не
перезапускался в рамках bounded verification strategy. Поэтому этот документ
не представляет `400/400` как подтверждённый результат.

## DJ6-BG-009 — bounded recursive-safe Telegram logging

- [x] Аварийный Telegram logging остаётся отдельным каналом и не смешивается с

- [x] Его failure path ограничен timeout/bounded fallback и защищён от

- [x] Ошибка Telegram transport не меняет результат основной business operation.

Acceptance evidence: необходимая Stage 3 migration chain применена без pending
migrations; management и storage acceptance probes вернули `200`,
`dangerous_backlog=0`.

## DJ6-BG-011 — явные sync transaction boundaries

- [x] Durable jobs получают persisted ID и открывают собственную синхронную
  transaction boundary вместо передачи ORM state между execution contexts.
- [x] Provider I/O не удерживает неограниченную DB transaction, а переходы

- [x] Неоднозначный provider outcome хранится как explicit ambiguous state и не
  объявляется автоматически ни успешной доставкой, ни безопасным retry.

Acceptance evidence: production queue snapshot имеет
`dangerous_backlog=0`; database connection snapshot `11/20`; текущий
